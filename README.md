# 🌈 Spectrum Sense

**Spectrum Sense** is a web-based screening tool designed to assess the risk of **Autism Spectrum Disorder (ASD)** in children using questionnaire responses and demographic data.
It provides meaningful insights to parents and educators through an interactive and user-friendly interface.

---

## ✨ Key Features

* 🔍 **ASD Risk Prediction**
  Predicts the likelihood of ASD using **M-CHAT** and **AQ-Child** questionnaire responses.

* 📚 **Educational Content**
  Access reliable articles and resources about ASD.

* 📈 **Milestone Tracking**
  Track age-specific developmental milestones for children.

* 📝 **Screening Questionnaires**
  Easy-to-use forms for parents to assess behavioral patterns.

* 👶 **Child Profile Management**
  Create, edit, and delete child profiles (age, gender, region).

* 📊 **History Tracking**
  View past screening results over time (overall or per child).

---

## 🛠️ Technology Stack

* **Frontend:** React, Next.js
* **Backend:** NodeJS, Python (Flask / FastAPI)
* **Database:** MongoDB Atlas
* **Machine Learning:** Random Forest Model

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/wxyzsxhz/Spectrum-Sense.git
```

### 2. Install dependencies

```bash
cd Spectrum-Sense
npm install
```

### 3. Run the application

```bash
cd frontend
npm run dev
```
